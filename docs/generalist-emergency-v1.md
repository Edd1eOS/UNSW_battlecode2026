# 紧急分裂出生证据 V1

独立候选 `opponents/generalist-emergency-v1` 复制冻结 V5，只修改紧急分裂提案。普通扩张、导航、食物/支付、身体验证及原 contact → continuation grade → possible birth 排序保持不变；没有地图、队伍或单位 ID 分组特例。

## 收窄后的合同

完整旧身体才能构造静止亲体与反转旧尾子体。子体朝向由已解析的 neck → head 地形步确定，包括门户。出生首步先查整个旧子体和静止亲体，之后才吃珠/移尾；不会假设尾部在碰撞前已释放。

每体最多 32 个搜索节点、两层续路，仅模拟每个未来动作的一步免费移动。子体两层搜索固定亲体；亲体搜索将子体占位视为可能移动/消失。未知格、未解析门户、外部单位可能先行动或预算耗尽均单列，不形成封闭证书。第二层是有条件的静态机会，不是未来存活保证。

“子体没有合法首步”不等于分裂无用：亲体可等待；长子体或亲体还可能再次分裂。因此只有完整两体都为 L2、都没有首步、没有任何未知/外部占位释放/预算分支时，才拒绝该紧急提案。更长无首步子体仍保留，仅在原安全层级全部相同后降低其效用；不会为了子体机会牺牲更强的亲体安全层级。

尺寸按原紧急尺寸，再尝试去重后的 2 与 L−2。Queen 原来未封闭时使用的子体 2 保留，不添加大子体来抢走 Queen 资本。两种尺寸出生 head/neck 和旧身体并集相同，首步几何不能因尺寸不同而变好；尺寸差异只能体现于移尾后的续路和亲体剩余资本。这里不把不同尺寸写成虚假的首步反例。

编译 `EMERGENCY_DISABLE` 恢复 V5 紧急提案，供固定消融。默认启用。指标记录两体首步闭路、深度、unknown/portal/budget 和拒绝数量。

## 官方规则核对

新固定回复 EngineModule 检查：L10 亲体 SPLIT6，L6 子体出生当轮干走 EE，下一轮仍为 L6。官方免费额度始终取动作起始长度 `ceil(L/4)`，没有“所有子体出生总共仅一步免费”的例外。旧 L2/L4 子体用例的免费额度恰为 1，不能外推到长子。新预测只使用每动作一条免费步这一最低能力，不改变真实免费额度。

## 验证与局限

C++/官方 WASM 场景覆盖：两 L2 闭路及 last-unit 的诚实 fallback、子体无首步但亲体可能等待、未知门、外部头可能先移动、不同尺寸移尾后的续路、Queen 原小子体、门户出生朝向、耗尽分支及 partial body；继承身体/支付/门户记忆、出生头和已知短路排序检查通过，关闭功能的旧紧急行为通过。

官方协议 35 个场景、38 帧通过，峰值 9,302,494 CPU 点。8 个合成历史 Atlas 预算场景覆盖完整 L8/L32、Queen/worker、环面/门户、4096 个旧已知格及当前 49 格观察，包含额外显式 assessment 和实际 `choose`，峰值 12,825,766。这不是生产普遍上界。未运行强度比赛。

该过滤很窄，可能只改变少量救援；无可救两 L2 时拒绝分裂也仍可能 fallback 死亡，不声称凭空制造存活。未解决上游进入陷阱、后手动态封口、长期资源收入或再次分裂资本链。候选只作为可解释机制实验。
