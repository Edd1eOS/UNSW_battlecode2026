# 联合投资第二版：终端责任与最长资本合同

独立复制冻结投资V1，仅增加两条普通投资筛选合同，不调整食物、支付、风险、探索或角色常数。Queen与最后单位重建、紧急分裂、已见碰撞、门后身体记忆和原contact→grade→birth→score顺序保持。

联合预测的两轮终点，对父子分别构造完整Simulation：使用该体预测身体、共享已吃珠集合，另一体全部旧身体加入blocked，正确覆盖输入里分裂前的父体占位。每体最低续路搜索horizon2、预算32；仅depth<2且没有视野外、未解析portal或预算耗尽分支时，拒绝该普通投资预测。这里是外部占位冻结条件下的有限路径证据，不是实际下一轮死亡证明；未知保留，不假设敌人不动。原beam的unknown/pruned记录其他被探索分支，不用于把选中路径判非法。

区域reserve/founder的普通投资，另要求预测两轮结束时 `max(parent长度, child长度) ≥ 当前parent长度`。普通采集体没有这条资本门槛，不恢复个人Atlas推全队人口目标，不把全部L8工龙永久禁止分裂。分裂只转移长度；同样净增两节的“8+2”和“6+4”，对当前L8资产具有不同最长机会成本。这是预测合同，真实子体会独立重规划，未来食物和最长资本都不保证兑现。

MOVE的联合终端和最长也记录，未据其改变原安全等级或强制淘汰MOVE。因此这不是全局两轮安全计划；普通投资被拒后，仍可能选出未来机会较脆弱的MOVE。联合模型仍冻结外国身体，没有实际父子计划传递，没有新增动态瓶颈预测、多源foraging或通道协作。

指标记录选中候选的terminal_parent/child_depth及grade、family_max_before/after；terminal grade采用最低两步时域，与原六/八步grade分开。拒绝普通提案另记计数、预测双方grade与max，以及reason：1父终端有限、2子终端有限、3区域最长资本未恢复。未知或穷尽标记保持原义，不能当实际收入账。

新场景验证同net的资本形状、孩子吃两珠后闭口、真实choose拒绝并记录reason、未知边界与耗尽不判死、另一体与旧neck占位。复用V1完整物理、固定免费额度、珍珠去重、同路径支配、身体记忆、Queen/last、紧急救援和有限分支排序回归。实际L6尾区资源仍选择SPLIT2；L8尾食明确触发资本拒绝；密食L8投资可通过资本合同但由更优MOVE胜出，未把全部生产提案阻断。
