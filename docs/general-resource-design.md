# 资源覆盖与双体投资：下一步实施合同

这是一份待实现方案，不改变已冻结的V3或Queen代理负责的V4。证据来自V3对risq-v的固定17场真实非排位对局；所有原replay的完整身体、终局和已执行吃珠/付费账均核验通过。它不能代表所有对手，也不能证明某个新算法会更强。

资源型败局同时缺覆盖和效率。Around UNSW吃珠417对2511，成功步数10672对31522，每千步吃珠39.1对79.7；Australia为193对1275、每千步27.5对48.1；Schooltime为167对2296、每千步45.1对82.6。相应付费成本只有21、8、5，不能把主要差距归因于资本支付。Slithery Fight终局已有27条，但Longest仍27对70，吃珠1197对2300；只增加数量也不足够。Maze与Autarky反而有较高每步资源效率，说明应依据机会和占位判断，不能给地图名写规则。

评分资产还会独立失衡。Dilemma总食530高于382、Longest19高于18，仍因Queen4低于18败；己方Queen仅吃1，对方吃15。Trauma双方Queen吃16对17，但己方转出8节、实际支付6节，对方转出4节且不支付，终局Queen6对17；该局己方仅一个单位死亡。它们分别是资源分配和活资产支出的证据，不支持把每次败因都归结为Queen首次死亡。

目前两项政策门槛与物理合法性无关。`desired=min(unit_limit,24,max(4,food_sites/2+frontiers/6))`用本单位的观察图估全队需求；该图包括历史Atlas、短期可信食物及边界，并非只有当前7×7，但也不是全队地图或人口容量。L≥8且单位数≥3又会永久分配储备，直接停止普通复制。真实UNSW局4106/5393个工龙行动标记为储备；大量出生长龙继承资本，不代表它们自主收集了相同长度。

`tests/generalist_population_gate_test.cpp`把门槛因果单独复现：同一49格已见区域、L6身体，切出L2后父子分别有六步完整合法续路；单位数10时目标为4，普通复制被禁；只把单位数改成2就选择分裂。完整L8输入另外核验永久储备赋值。该构造证明政策行为，不冒充真实replay某次未分裂的唯一原因。原replay没有全部私有Atlas、足迹和每帧刷新倒计时，不能凭终局数量重建那些决策原因。

下一步应把复制定义为一次有代价的覆盖投资，继续使用统一候选管线：

1. 全队数量只用于官方unit_limit及最后单位重建，不再用单个观察图算硬性全队目标。普通工龙提出分出L2的候选，Queen仍只在重建或救援时提出复制。
2. 每个复制候选模拟父体静止、尾段反转为子体、子体同轮行动的真实顺序。父子互相占位、旧尾碰撞、出生方向、起始免费额度和珍珠去重都按官方规则检查。先找子体至少一条合法免费首步，再评估父体下一轮与子体后续的联合路径；未知身体或门出口单独标不确定。
3. 用同样的两轮局部时域比较“不复制的最佳移动”和“复制后的父子联合行动”。估计收入为两体不同珍珠的并集减实际模拟支付，不能两条路径重复记同一珠；复制本身只转移长度，不算收入。成长资产另计父体长度损失及可见头风险，保持Queen首评分和最后幸存者保护。
4. 无可见收入时，探索投资单独记价值：子体能否到达父体暂不可达的已知支路、不同观察边界或解析后的门区域。只算额外覆盖机会，不把未知区域假装有食物。若两体去同一路、尾区被当前友军堵住、或两体都只能在同一小圈重复，则不因“有出口”就加人口。
5. 资源目标改用多源反向距离场传播若干新鲜食物、可信刷新点和探索出口，而非只有一个固定目标。路径成本包含真实已解析门、可见竞争、身体释放的可执行前缀及无收益回访。身体暂时阻路和永久地形断开要区分；无法到达的目标不能持续吸引评分。

成长角色应描述当前区域的计分资产，而不是“所有L8工龙永久不复制”。保留最初工龙已完成一次扩张后的持续储备；自然长工龙只在当前看见的竞争者中选区域冠军，比较已知自身长度与对方可见长度下界，平局用稳定ID打破。没看见更长者不证明全队第一；区域外可各有冠军。已经保留的长资本不因人口中期变化自动取消保护，但复制仍可通过联合投资比较进入候选，不能让一个角色布尔值永久否决高收益扩张。

无收益循环必须先分类。Schooltime M1249241的Queen连续498个已执行无食移动、末50轮仅四个不同头位置；进一步核验普通地形连通分量恰四格、没有portal，四格及全部边均在该Queen当前合法视野内。这个永久隔离圈合理保住Queen评分，不是探索失效证据，资源覆盖应由其他工龙完成。只有曾观察到可达边界或资源、联合路径没有进展，并重复相同头/方向状态时，才启动有限探索预算。未知出口仍不是安全；允许免费探索与是否花长度必须分开，不全局降低Queen避头风险。

建议先做投资合同的独立场景，再编写候选：全队10条但尾区有新增资源应允许提案；两体争同珠只算一次；无资源同圈不得复制；子体旧neck和父体阻挡不得通过；已见更长区域工龙抑制第二冠军，但远方未知工龙不作为比较对象；无免费出口时保留真实应急分裂。首版限制为两轮、联合beam宽4、约200节点预算，并始终保留单步移动。预算耗尽报告不确定，实际CPU上限由正式协议计量确定。之后冻结新源码和从未开启的外部种子，以净资源、人数覆盖、最长资本流失及正式胜负共同验收，不用自家版本胜率替代外部评估。
