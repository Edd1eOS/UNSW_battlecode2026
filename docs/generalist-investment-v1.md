# 双体资源投资首版

候选独立复制冻结generalist-v5，未修改主bot或旧候选。实现范围只有双体投资与区域资产角色；Queen、最后幸存者、出生头威胁、门后身体记忆、旧尾碰撞及资本支付保护沿用V5。单一目标Atlas导航仍保留，本版没有实现消息传播或多源全队资源分配。

普通工龙L≥6可提出分出L2；全队数量只约束官方上限和最后单位重建，不再由个人Atlas推导人口目标，也不因reserve布尔值直接否决。Queen仍仅重建或救援时分裂。完整身体才能计算普通联合投资；部分身体、未解析出生方向及没有完整可执行预测的提案暂不采用，救援分裂仍保留。

两种行动用相同的两轮时域。MOVE包括当前候选移动与下一轮本体移动；SPLIT包括本轮父体静止、子体出生后移动，下一轮父体先动、子体后动。每次行动免费额度固定于该体行动起始长度，付费可负担检查在移动前，所有旧身体及旧尾碰撞在吃珠和扣长度之前。父子共享已吃珠集合，分裂仅转移资本，不制造收入。移动已经吃的珠和付费不重复加分。

联合beam宽4，每行动最多六步；分裂提案总320节点，移动下一轮96节点。返回完整已见时序、未解析分支、节点耗尽、beam剪枝分别标记；“完整”只表示选中时序的每步都可模拟，不表示穷尽全部选择或未来真实安全。其他单位当前身体冻结，未来头威胁仍是当前输入的估计。子体下一回合独立决策，父体不能命令它照预测执行。

经济支配在原有直接头接触、续路等级、可能出生头风险之后判断：只有同一条不更弱的MOVE，净食物、边界机会和软风险都不劣，才能否决普通投资。不能把两条MOVE各自最好的维度拼成不存在的支配点，也不能让高食物短死路压掉强续路提案。已见不同珍珠并集减模拟支付是预测净增长；`joint_food_est`/`joint_paid_est`不是已执行账。探索是到已知观察图边界的距离势，两体同一边界格只记一次，不假设未知处有食物；相邻边界格仍可能属于同一区域，不能称独立资源区数量。

初始工龙完成一次扩张后的founder储备持续保留。自然长工龙依据当前可见友军头及可见链长度下界选区域资产；看见更强者可退出自然champion角色，没有看见更强者不证明全队最长。角色影响风险和切走两节资本的代价，不再一票停止复制。区域角色及净增长预测仍可能分散全队长度，本版不宣称两轮资源收益保证终局Longest；外部验证必须同时审父子净增长、家族最长资本、继承长度、存活和正式胜负。

固定编译开关仅用于机制消融：`INVESTMENT_DISABLE_JOINT`恢复V5投资门槛与下一轮食物加分；`INVESTMENT_KEEP_V5_ROLES`恢复V5储备规则。默认参赛均不定义，运行协议没有新开关。

独立场景覆盖单位数10但尾区资源可获利、空闭区不复制、父子与旧尾碰撞、固定L4免费额度跨L5、珍珠去重、同分支支配、有限食物诱饵、实际可见九节竞争者及继承V5身体/资本/最后幸存者回归。官方协议只验证接口、合法场景与计算预算，不代表线上强度。真实执行收入由外部完整replay另行核对；不使用自家版本互打作为验收。
