# 多资源距离场首版

本候选独立复制冻结 generalist-v5，只替换存在资源时的单目标导航加分。它检验 H2：多个可达机会的聚合能否改善资源效率和终局资本。不是全图透视，也未合并探索或父子投资；Queen、出生头风险、身体物理、人口门槛和最终安全排序不变。

在自己亲眼观察并记忆的地图上，最多展开2048个位置，当前可见其他身体阻断边；自身旧身体允许导航估计跨越，但最终行动仍逐步模拟旧尾与支付。未解析门户不连到猜测出口，已解析门户按真实图边计一步。

选最多16个可达资源格，按当前可信度和初始图距离截取。当前珍珠权重1；十轮内的历史珍珠按年龄降到不超过0.45；八轮内的可见刷新倒计时权重不超过0.2，并按到达时间与刷新时间差折扣。历史资源和未来刷新都只是导航机会，不写入收入账。该截取会漏掉更远的大资源区，图搜索耗尽也不证明其余地图不可达。

每个资源格反向搜索至16步，得到到该资源的图距离 d。端点势为各不同资源的 `weight / (1 + 0.35*d/free_steps)^2` 之和；导航加分为端点势减起点势，乘35并截在±70。一个稍远的资源簇因此可能超过一颗孤立的近珠。已经模拟吃到的珠从两端势同时去掉，实际收珠只由物理模拟奖励一次。

这是方向启发式，不是可依次吃完全部资源的路径证明；多个资源的贡献可能竞争同一段路。16步也不保证16步后安全。无可证资源源点时仍用原来的边界导航。它不绕过直接碰撞、续路等级或出生头风险，付费和风险权重保留V5。没有针对地图名、对手名或单场时刻的分支。

验收仍分别对相同外部对手、地图、种子和先后手比赛，不安排自家版本互打。主指标是整场及共同前缀的净收入、每千成功步资源效率和终局Queen/Longest；源点增加、步数增加及弱对手胜场不单独构成采用依据。测试前登记本设计；冻结源/WASM和实际结果另写证据清单。
