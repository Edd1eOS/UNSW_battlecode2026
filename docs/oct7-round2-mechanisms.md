# 第二轮新增算法：原理与已验证边界

这轮保留五份冻结源码，但只有两项策略假设：更远的死胡同识别、评分资产的资源分工。Evidence V1是动作检查重构；两项策略各有一个针对明确问题的修正版。编号用于把实际比赛绑定到准确源码，不代表后一个版本一定更强。

## 统一动作证据

`action_evidence.hpp`把MOVE的每一步、SPLIT、明确的敌方Queen牺牲和最终兜底分成四类：当前输入可执行、输入不足、已知失败、明确牺牲。每一步都按先检查支付能力、再检查旧身体碰撞、然后收珠和更新尾巴的顺序模拟。到未知区域只能提交最后一步，不能继续猜后面的路线。

“可执行”只说明当前这次动作符合所知物理，不保证敌人行动后的下一回合安全。SPLIT合法也不等于父子未来能活。初始身体只知道前半截时不能补造剩余身体。

Evidence V1对固定外部程序完成88场，逐条核对后，全部88场的行动和物理/资源事件与V5一致；诊断文字和计算开销不同。它可作为可解释的实验底座，尚不是实力升级。

## 有方向的死胡同图

普通BFS能告诉我们“从这里能到哪些格子”，但龙不能立刻回头踩自己的脖子。于是把状态写成“上一个格子 → 当前格子”。同一格子从不同方向进入，出路可能完全不同。

Topology先在记忆中的地图上建立这些有向状态，再反向标记能通向未知边界的路线，并反复移除没有后续路线的状态。最后区分三种情况：能到已知循环、可能有未知出口、确认只有有限条路。这样可识别原来只搜索6/8步看不到的长死胡同。地图和门户都来自本龙观察记忆，不读取回放的全图给参赛程序。

循环只是地形条件：一个小圈可能容不下长身体，也可能正被敌人堵住。因此V1把地形排在身体短期续路之前会有问题。构造检查中，西侧循环被身体堵住，北侧有限长分支仍可走；V1选西，V2选北。V2只在相同接触风险和身体续路等级下比较地形。最后一轮若有限路线已足够撑到结束，仍允许去吃珠；普通工龙保留原采集偏好。

两份真实maze首个分歧的合法输入也连续复现成功：A侧前137回合、B侧前107回合动作相同，到分歧处立即结束输入。A侧原动作`WWNNN`吃1颗、后续地形仅剩2步；新动作`W`当回合不吃。B侧原动作`WNNWS`吃4颗、后续地形仅剩5步；新动作`W`不吃。这个检查解释了为什么改动作，不能证明改后能赢。完整比赛中两版仍有Longest下降，所以构造正确不能替代采用验证。

64×64完整记忆的初版压力样本曾超过9000万点，尚未开赛。改成连续数组保存反向边、避免反复找方向编号后，同一算法的8个压力样本最高约4481万点；每个样本包含两次建图，仍不是所有未来输入的预算上界。

## 资源机会成本

普通工龙看到友方Queen时，把Queen在保守免费配额内能到达的当前可见珠子视为有机会成本。看不到Queen时，才考虑可见长度下界至少8、且比自己的身体长的队友。长度只是可见链的下界，不能假装知道远处整条龙有多长。

Queen机会成本65分，其它长龙45分，食物本身仍有110/130分。因此这是一项软折扣，必要时仍可以自己吃。估计不穿当前身体，不越未知门户，不认领敌头直接威胁处的珠子；最后一轮已经行动的低id队友不再拥有下一次采集机会。Queen自身不让食。

V1只扣当前动作实际计划吃到的珠子，却对下一免费窗口吃同一颗珠保留满额45分预测奖励。V2在同一条未来见证路线中同时记录食物与机会成本，对未来奖励使用同样的折扣比例，并且只计下一固定免费窗口，不重复扣已经在当前动作吃到的珠子。等深度有限分支的食物和成本必须来自同一条路线。

这仍是局部估计，不是全队统一预约，也不等于Queen承诺下一回合会来吃。不能把标记数量、让路次数或分裂继承的长度记成收入；收入只从实际比赛中的收珠和支付事件核算。

## 如何读测试结果

每版独立打固定外部对手，没有自家新旧互打。主发现是同22图换边88场；有效配对交集另列，正式88场不能删掉。公开KGTS另44场用于对手敏感性，它也不能代表成熟天梯水平。

报告同时保留整场终局、双方共同实际时间前缀、每一回合的Queen/Longest差值和净保有轨迹。较晚检查点只包含两场都还没结束的配对，所以分母会减少；不会在已结束的比赛后补造行动或收入。领先必须按实际Queen优先级解释，不能把总资源增多直接当成胜率提升。
