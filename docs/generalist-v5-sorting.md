# V5：出生头风险与续路证据的比较顺序

V5独立复制冻结V4，只改变候选排序。保留V3对当前可见敌头直接一步接触的保护，随后比较续路证据等级，再在同等续路等级内避开潜在的分裂出生头，最后比较原分数。出生预测、软风险成本、资本支出约束、角色、分裂条件和搜索预算都不变。

独立控制场景中，Queen L2向北只有两步可走的永久窄叶路，向东有完整八步续路但可能遭敌尾分裂子体攻击。V4把潜在出生风险放在续路等级之前，选择北路；V3对照与V5选择东路。北路没有未知出口、预算截断或移动外体阻挡，L2也不能靠支付或分裂脱困。这个构造证明排序缺陷，不冒充真实比赛结果。

STAR真实局部观察另核验原E端点和替代端点都有八步续路。在这一相同等级内，V5仍选择避开可见尾段反向子体攻击的替代。必要的净负付费逃生及原身体/支付/协议场景继续验证。

完整八步是静态局部证据，不是对下一轮敌人动作的安全保证；潜在出生头也不是已证敌人必然分裂。V5不会为了这种可能性改选更弱的有限续路，但可能因此接受完整续路上的潜在攻击。未知出口仍保留自身等级，所有实战强度判断等待新冻结种子的外部结果。
