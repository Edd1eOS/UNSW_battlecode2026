# 通用计分规划器：generalist-v1 实施说明

独立候选在 `opponents/generalist-v1/`，根 `bot/` 保持不变。它把移动、有限支付加速、复制、已核验的敌 Queen 交换和未知 portal 探索放进同一条候选管线，不按地图名、对手名、队伍或 ID 取模选择策略。它是等待外部检验的实验，不是已证明的强度升级。

官方目标是消灭对手即胜、己方被消灭即败；双方仍存活时，终局按 Queen → Longest → Total 比较。7×7 输入只提供自身长度、己方单位数及局部视野；看不见 Queen 不等于 Queen 已死，可见敌身体长度下界也不是完整长度。

此次固定100场外部观察有54败：26 Longest、20消灭、8 Queen。75次己方 Queen 死亡中51次头碰头、14次墙、10次其他身体；26个 Longest 败局仅5场己方历史峰值超过敌方终局最长，1场持平，20场仍不足。这支持同时检查增长积累和关键资产存活，不支持只把分裂关掉。网页付费冲刺次数是尝试统计，不能当已执行费用。SVG采样曲线虽全部通过四项终局姓名列核验，仍不能证明逐轮领先、食物账或死亡因果。

候选保留原有 `Atlas` 地形记忆、合法 portal 解析和身体模拟，替换原 `forage` 的多个提前返回。每个当前动作前缀都检查实际顺序：免费步数固定为起始长度的 `ceil(L/4)`；付费前先检查可支付；整个旧身体包括旧尾参与碰撞；安全落点才吃珠或移除普通尾，最后移除付费尾。当前计划账单是可见珍珠数量减付费节数，未来食物机会另记 `next_food_est`，不会伪装成已执行收入。

三个职责使用同一合法性检查。Queen保有首评分资产；工龙达到L8且己方至少3条，或最初工龙已完成一次分裂，就永久进入储备角色。中期人口下降不自动取消储备，只有己方剩1条时可重建。其余采集者达到L6，且局部资源/探索需求允许时，可分出L2子体。分裂只转移长度，不算新增食物；子体头是旧尾，方向按反转身体及 portal 边核验，父子占位与子体出口一并检查。普通敌工龙头撞交换被禁用；敌 Queen 交换需要合法可达路径和己方评分幸存者条件，储备者还要求当前看见己方 Queen。

搜索采用宽12的beam，本回合最多6个微步，且最多额外支付2步。先精算合法前缀，再为廉价分数前8个及每个方向的单步保底候选检查静态续路；Queen目标8步，每候选140节点，工龙目标6步、90节点。搜索预算耗尽、已观察视野外和未知 portal 分开标记，均不是安全证明。Queen与储备者在有至少不确定续路的候选中，先避开当前可见敌头直接一步接触，再比较续路等级和净增长等分数；远距离可达风险保持软成本，不把多个小权重相加当确定致死。已核验的敌 Queen 交换是明确牺牲候选。

远期目标是在已观察地形上做2048节点上限的BFS和反向距离场，结合新鲜食物、可信刷新倒计时、探索边界和访问次数。portal不使用曼哈顿距离假定；旧敌人不成为永久障碍。资源不足时边界价值提高，频繁无收益绕圈会受足迹成本惩罚。未知落点最多作为一次实际探索，不编造后续路径；任何不可见末端移动之后清除预测身体并重新观察重建，防止多步前缀遗漏后错误标成完整身体。

官方 WASM 场景检查覆盖支付顺序和免费额度、旧尾碰撞、当前净增长、普通工龙碰撞否决、储备持续性、普通复制、子体方向、预算不确定性、不可见末端记忆、未来食物同路绑定及直接接触排序。协议与运行预算检查不计胜负。强度验收交给外部对手面板，并保留发现集与未参与设计的验证集；不以新版本对自家旧版本的胜率作为验收。

当前限制：续路是静态局部证据，不能预测隐藏敌头、真实下一轮敌人动作或全队冠军；未来食物和子体收益只是估计。储备比例、扩张需求和未知区域暴露仍需外部结果判断，不能从少数曲线样例推出最佳阈值。
